# Blank private-note templates

Copy each heading into its corresponding private file only if that file does not
exist. These are empty templates, not records of real events.

## LEARNINGS.md

```markdown
# Technical lessons

Concise corrections and verified lessons. Private local records.
```

## ERRORS.md

```markdown
# Technical errors

Unresolved or recurring failures. Separate observations from suspected causes.
```

## FEATURE_REQUESTS.md

```markdown
# Requested capabilities

Explicit user requests only. Entries do not authorize implementation.
```

For the entry format and writing boundaries, read SKILL.md. Do not add invented
occurrences to real records. Do not copy credentials or private transcripts.
